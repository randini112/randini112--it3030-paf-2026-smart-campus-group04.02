🎓 Smart Campus Management System

A web-based Smart Campus Management System developed as part of the IT3030 Project.

The system is designed to improve campus operations by providing a centralized platform for students, staff, and administrators to manage campus-related activities efficiently.

🚀 Features

- Student Management
- User Authentication & Authorization
- Ticketing / Support Management
- Campus Service Requests
- Real-time Data Management
- Responsive User Interface
- Secure Database Operations

🛠️ Technologies Used

Frontend
- React.js
- HTML5
- CSS3
- JavaScript

 Backend
- Spring Boot
- Java

Database
- MySQL / MongoDB

 Version Control
- Git
- GitHub

 👥 Team Project

This project was developed collaboratively as part of the IT3030 module coursework.

 🎯 Objectives

- Digitize campus administrative processes
- Improve communication between students and staff
- Provide a user-friendly campus management platform
- Enhance efficiency through automation
